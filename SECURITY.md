# Security

Please do not open a public issue for a security vulnerability.

Use a private GitHub Security Advisory and include only the details needed to reproduce the problem. Never
include an API key, authorization header, private page content or credential fragment in an issue, pull
request or log.

Baleen stores provider keys locally in the Chrome profile and sends capture data directly to the selected
provider for normalization. Remove test keys from the profile after an investigation.

For non-sensitive bugs, open a regular issue without private data.
